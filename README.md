# Project Title

Development if E-Commerce Web Application for MQ Kitchen Store

## Description

The E-Commerce Web Application for MQ Kitchen Store is a robust and user-friendly online platform designed to streamline the process of browsing, purchasing, and managing kitchen-related products. This web application provides an intuitive interface where customers can explore a wide range of kitchen essentials, add items to their cart, and securely complete transactions through available payment methods, including cash on delivery and GCash.
